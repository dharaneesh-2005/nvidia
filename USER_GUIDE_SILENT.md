# Interview Helper - User Guide (Silent Mode)

## Installation

1. Run `InterviewHelper-Setup.exe`
2. Click through installer
3. Done!

---

## Usage

### Start the App:
- Double-click "Interview Helper" icon on desktop
- **No windows will appear** - it runs silently in background
- Just open your phone and go to: **https://helper.pinmypic.online**

### Stop the App:
- Click "Stop Interview Helper" in Start Menu
- Or run Task Manager and end `interview_helper.exe` and `cloudflared.exe`

---

## Your Permanent URL

```
https://helper.pinmypic.online
```

Bookmark this on your phone!

---

## How to Know It's Running?

- Check Task Manager for `interview_helper.exe` and `cloudflared.exe`
- Or just try accessing the URL on your phone
