# Quick Reference - Pinggy Setup

## For You (Developer)

### One-Time Setup:
1. Download pinggy.exe from https://pinggy.io
2. Place in interview-helper folder
3. Build: `iscc setup.iss`

### Files in Installer:
```
✅ interview-helper.exe
✅ pinggy.exe
✅ config.json
✅ profile.json
✅ static/
✅ start.bat
```

---

## For Users

### Install:
1. Run InterviewHelper-Setup.exe
2. Done!

### Use:
1. Click "Interview Helper" icon
2. Note the URL from Pinggy window (first time only)
3. Bookmark URL on phone
4. Access from anywhere!

### URL Example:
```
https://rndmxyz-12-34-56-78.a.pinggy.io
```
(Same URL every time!)

---

## Benefits

✅ No account/login needed
✅ No config files
✅ Persistent URL
✅ Works from anywhere
✅ HTTPS automatic
✅ 2 files only (vs 4 with Cloudflare)

---

## Commands

**Start:** Double-click desktop icon
**Stop:** Press any key in window
**URL:** Check Pinggy window

That's it! 🚀
