# Interview Helper - Simple Setup

## Installation (One-Time)

1. Run `InterviewHelper-Setup.exe`
2. Click through the installer
3. Done!

## Usage

1. Double-click "Interview Helper" icon on desktop
2. Wait 5 seconds
3. Open your phone browser and go to: **https://pinmypic.online**
4. That's it!

## Your Permanent URL

```
https://pinmypic.online
```

This URL never changes. Bookmark it on your phone!

## Stopping the App

Press any key in the Interview Helper window.
