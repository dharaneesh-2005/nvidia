🔍 Search Logging Demo

This page demonstrates the comprehensive logging system for manual search queries.

How to Test Search Logging

Instructions:

1. Open the main application: http://localhost:3000/
2. Press Ctrl+Alt+S to open the search modal
3. Type a question like: "What is 2+2?"
4. Press Enter to submit
5. Check the browser console (F12) and server logs
What Gets Logged

🔵 Frontend Logs (Browser Console):

🔍 [SEARCH LOG] Submitting manual question: What is 2+2?
🔍 [SEARCH LOG] Message payload: { "type": "manual_question", "text": "What is 2+2?", "auto_index": false }
🔍 [SEARCH LOG] Sending via WebSocket
🔍 [SEARCH LOG] Received transcription from backend: What is 2+2?
🔍 [SEARCH LOG] Received answer from AI model (length: 156)
🔍 [SEARCH LOG] Answer preview: The answer to 2+2 is 4. This is a basic arithmetic operation where we add two numbers together...

🟢 Backend Logs (Server Console):

🔍 [SEARCH LOG] Received manual_question: 'What is 2+2?'
🔍 [SEARCH LOG] Processing question: 'What is 2+2?'
🔍 [SEARCH LOG] Conversation history length: 4
🔍 [SEARCH LOG] History[0]: user - 'Previous question about programming...'
🔍 [SEARCH LOG] History[1]: assistant - 'Previous AI response...'
🔍 [SEARCH LOG] Sending to AI model: 'What is 2+2?'
🔍 [SEARCH LOG] AI response received (length: 156)
🔍 [SEARCH LOG] AI response preview: 'The answer to 2+2 is 4. This is a basic arithmetic operation...'
Log Analysis

The logs show you:

  • ✅ Exact question sent: What the user typed
  • ✅ Message payload: The JSON structure sent to backend
  • ✅ Conversation history: Previous messages sent to AI for context
  • ✅ AI model input: The exact question sent to the AI
  • ✅ AI response: The full response from the AI model
  • ✅ Timing information: When each step occurs
Troubleshooting

If you don't see the expected question being sent:

  • 🔍 Check if the frontend logs show the correct question
  • 🔍 Verify the WebSocket connection is working
  • 🔍 Look for any error messages in the logs
  • 🔍 Check if the conversation history contains unexpected content
