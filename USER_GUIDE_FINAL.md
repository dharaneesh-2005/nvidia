# Interview Helper - User Guide

## Installation

1. Download `InterviewHelper-Setup.exe`
2. Run the installer
3. Click "Next" → "Next" → "Install"
4. Done!

---

## Usage

### First Time:
1. Double-click "Interview Helper" icon on desktop
2. Wait 5 seconds for startup
3. Open your phone browser
4. Go to: **https://pinmypic.online**
5. Bookmark this page!

### Every Time After:
1. Click "Interview Helper" icon
2. Open bookmarked page on phone
3. Done!

---

## Your Permanent URL

```
https://pinmypic.online
```

**This URL never changes.** Bookmark it once, use it forever.

---

## Stopping the App

Press any key in the Interview Helper window.

---

## Troubleshooting

**Q: Page won't load?**
- Make sure Interview Helper is running (check for window)
- Wait 10 seconds after starting
- Check your internet connection

**Q: Can I use it on multiple devices?**
- Yes! The URL works on any device with internet

**Q: Is it secure?**
- Yes, uses HTTPS encryption
